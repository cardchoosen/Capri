本机执行与权限

命令只在当前会话工作区内启动，并由操作系统沙箱限制文件访问、写入和网络。默认每条命令都需审批；审批绑定命令与工作目录。取消会终止命令进程树；服务重启后不会自动重跑，只保留中断回执。
