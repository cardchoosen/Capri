# Capri UI 0.1

视觉目标是精简、清晰、有锋芒。黑色作为主要留白；绿色用于主操作、活跃状态与身份标记；红色用于设置入口、停止和异常；白色承载主要内容。灰色只用于白色/黑色之间的层级。

| Token | 色值 | 用途 |
| --- | --- | --- |
| Ink | #080B09 | 主背景 |
| Panel | #111612 | 输入、用户消息 |
| Line | #29322B | 细边框与分隔线 |
| Green | #A5FF75 | 主操作、运行与Capri标识 |
| Red | #FF514F | 停止、异常与标识 |
| White | #F4F6F3 | 主内容 |
| Muted | #939E94 | 次级说明 |

布局使用 4/8dp 节奏、聊天/运行页16dp边距、2–4dp小圆角；发送按钮、输入框、用户消息及代码块使用2dp圆角。技术标签使用小字号等宽字，正文优先可读性。首屏使用抽象双折线标记，避免角色素材版权和形象绑定影响工程迭代。

导航只有对话、文件、运行三个一级入口。左侧抽屉管理会话，右上角管理模型配置。会话与执行状态来自ViewModel；文件、模型接口、执行环境分别在独立实现文件中，后续可以替换页面而保留业务层。

后续拆分每个Tab为独立Composable；增加文件预览和流式输出时沿用现有颜色语义与留白。

## 回复排版

Assistant回复按CommonMark解析，支持标题、加粗/斜体、链接、引用、有序/无序列表、行内代码、代码块、GFM表格与删除线。用户消息和工具日志保持原文，避免误解释脚本输出。正文15sp；代码13sp等宽字体；表格独立横向滚动，长代码不强制折行。代码块提供语言标签与原文复制；整条回复可复制原始Markdown（包括表格）。渲染组件独立在MarkdownReply.kt，解析结果按消息内容缓存。

## 工具记录与键盘

仅对话页使用ToolOutputRow；运行页仅展示环境、初始化/探针结果与原生能力入口，不展示当前会话工具记录。工具结果默认折叠为单行灰色动作文字和紧随文字的箭头，无背景、边框、图标或第二行状态。正常完成不重复标注，异常或需要授权等状态在同一行提示，长文字省略。折叠行最小28dp，与相邻消息间距6dp；普通消息之间为18dp。展开后可滚动查看、选择和复制输出。折叠不修改原始记录，内部profile_search仍隐藏；聊天列表用会话ID+消息位置保持展开状态独立。

底部导航保持48dp固定布局及系统导航安全边距，不随键盘可见性插入/移除；键盘覆盖底部导航。内容先应用并消费Scaffold的padding，再通过imePadding补足剩余键盘高度，避免收起末尾导航重新加入造成二次上跳。输入框常规底边距6dp。消息被send接受后清空输入、清除焦点并收起键盘；配置缺失导致发送失败时保留草稿和键盘。

## 会话滚动

ChatScrollState 在 Tab 内容外按会话 ID 缓存在内存，记录 LazyListState、消息计数和是否跟随底部；离开 Tab 或切换会话不丢失位置，应用重新启动则从最新消息开始。列表使用 reverseLayout 和倒序消息、原始消息位置作为稳定 key，索引0即底部，无需首次进入后长距离滚动。只在可见消息数变化且用户原本停留底部时立即定位到底部；上翻阅读时不抢位置，主动发送消息恢复跟随。工具进度、权限或其他refresh不触发滚动，移除全局update驱动的animateScrollToItem。

## 持续终端入口

运行页的「持续终端」按需打开管理面板，不展示聊天工具历史。面板提供终端选择、新建、命令输入、输出查看、中断、关闭和已关闭记录删除；关闭面板不停止任务。后台电池设置按钮仅打开 Capri 自身应用信息，由用户调整系统策略。聊天中的 terminal 调用继续沿用单行折叠样式，运行与失败状态在同一行表达。

## 失败状态

工具折叠行区分参数不合法、权限受限、命令退出码、超时、输出上限和中断，保持单行。模型请求失败单独提示回复未完成、已有工具结果保留及“继续”接续方式，不暗示执行结果回滚；短暂重试只更新思考进度，不新增工具记录。
