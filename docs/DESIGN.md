# Capri UI 0.1

视觉目标是精简、清晰、有锋芒。黑色作为主要留白；绿色用于主操作、活跃状态与身份标记；红色用于停止和异常；白色承载主要内容。灰色只用于白色/黑色之间的层级。

| Token | 色值 | 用途 |
| --- | --- | --- |
| Ink | #080B09 | 主背景 |
| Panel | #111612 | 输入、用户消息 |
| Line | #29322B | 细边框与分隔线 |
| Green | #A5FF75 | 主操作、运行与Capri标识 |
| Red | #FF514F | 停止、异常与标识 |
| White | #F4F6F3 | 主内容 |
| Muted | #939E94 | 次级说明 |

布局使用 4/8dp 节奏、20–28dp页面边距、12–14dp常用圆角。技术标签使用小字号等宽字，正文优先可读性。首屏使用抽象双折线标记，避免角色素材版权和形象绑定影响工程迭代。

导航只有对话、文件、运行三个一级入口。左侧抽屉管理会话，右上角管理模型配置。会话与执行状态来自ViewModel；文件、模型接口、执行环境分别在独立实现文件中，后续可以替换页面而保留业务层。

后续拆分每个Tab为独立Composable、提取工具记录组件；增加文件预览和流式输出时沿用现有颜色语义与留白。

## 回复排版

Assistant回复按CommonMark解析，支持标题、加粗/斜体、链接、引用、有序/无序列表、行内代码、代码块、GFM表格与删除线。用户消息和工具日志保持原文，避免误解释脚本输出。正文15sp；代码13sp等宽字体；表格独立横向滚动，长代码不强制折行。代码块提供语言标签与原文复制；整条回复可复制原始Markdown（包括表格）。渲染组件独立在MarkdownReply.kt，解析结果按消息内容缓存。

## 工具记录与键盘

对话和运行页统一使用ToolOutputCard，工具结果默认折叠，只显示操作名称、结果状态与展开入口；展开后可滚动查看、选择和复制完整输出。折叠不修改原始会话记录，内部profile_search仍隐藏。聊天列表用会话ID+消息位置保持卡片状态独立。

键盘Insets统一由Scaffold外层处理，内容消费Scaffold提供的padding；输入框不再重复叠加IME边距。键盘打开时隐藏底部导航，只保留输入框8dp的常规底边距。消息被send接受后清空输入、清除焦点并收起键盘；配置缺失导致发送失败时保留草稿和键盘。
