# Capri UI 0.1

视觉目标是精简、清晰、有锋芒。黑色作为主要留白；绿色用于主操作、活跃状态与身份标记；红色用于停止和异常；白色承载主要内容。灰色只用于白色/黑色之间的层级。

| Token | 色值 | 用途 |
| --- | --- | --- |
| Ink | #080B09 | 主背景 |
| Panel | #111612 | 输入、用户消息 |
| Line | #29322B | 细边框与分隔线 |
| Green | #A5FF75 | 主操作、运行与Capri标识 |
| Red | #FF514F | 停止、异常与标识 |
| White | #F4F6F3 | 主内容 |
| Muted | #939E94 | 次级说明 |

布局使用 4/8dp 节奏、20–28dp页面边距、12–14dp常用圆角。技术标签使用小字号等宽字，正文优先可读性。首屏使用抽象双折线标记，避免角色素材版权和形象绑定影响工程迭代。

导航只有对话、文件、运行三个一级入口。左侧抽屉管理会话，右上角管理模型配置。会话与执行状态来自ViewModel；文件、模型接口、执行环境分别在独立实现文件中，后续可以替换页面而保留业务层。

后续拆分每个Tab为独立Composable、提取工具记录组件；增加文件预览和流式输出时沿用现有颜色语义与留白。
