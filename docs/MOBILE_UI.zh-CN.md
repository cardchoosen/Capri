# 移动端基础 UI

2026-11-02。本专项完成基础信息结构、用量页面和详情交互统一，角色形象、红色电流、能力动画与人格文案继续由角色设计专项负责。

## 导航与设置

底部导航为「对话 / 文件 / 用量 / 设置」，原「运行」页拆分为分组设置和独立用量页。导航切换收起键盘，不更改选中的对话、消息、模型或工作区。对话顶部「工作台」提供当前对话浏览器与持续终端；关闭详情不会停止已有任务。

设置使用图标、标题、说明、可选状态与箭头组成的列表，分组如下：

| 分组 | 内容 |
| --- | --- |
| 模型与账号 | 模型配置、全局 Git 账号、全局 SSH 身份 |
| 能力与扩展 | Tools、MCP、Skills、增强能力 |
| 记忆与规则 | 记忆与资料、全局及当前对话规则 |
| 连接与权限 | 电脑网页连接说明、Android 权限与能力 |
| 环境与存储 | 执行环境、安装环境档案、存储管理与维护 |
| 高级与关于 | Root 授权及核验、版本与运行说明 |

Tools、MCP、Skills 入口直接打开对应分类。公共 Skill 仓库入口移至 Skills 内，可同步及查看待处理贡献。Root 与环境原理移入二级页面。SSH 沿用环境就绪限制；清理沿用范围说明、占用检查和明确确认。存储页显示设备分区可用空间，不将其标成应用占用。

## 用量与数据口径

账号余额使用现有服务商接口。官方 DeepSeek 账号支持查询，其他账号明确显示暂不支持。每个接口/凭据作用域分别缓存最近成功余额与时间；进入页面时一分钟内复用缓存，允许手动刷新。刷新失败保留旧值并提示已过期，失败不替换为零。不保存 API Key 到余额缓存。

本机统计异步读取各保留会话 metrics 目录，按记录更新时间选择最近最多 120 个日志，每份最多 256 KiB；不读取工作区文件或对话正文。统计模型请求次数（包含重试）、已完整上报的输入/输出 Token，以及模型请求累计耗时。Token 仅从成功的 model_parse 事件读取，避免与 model_request 重复累计；缺失、非法数据不算零，不计入完整上报次数。残缺日志仍保留可读取事件并显示统计不完整说明。

这些是本机诊断记录，不是服务商账单、实时全局账户消费或所有历史用量。聊天删除后统计可减少；旧记录不补造账号归属、日期账单或价格估算。进入用量页读取一次，手动刷新，不轮询日志或余额。

## 详情与反馈

共享全屏详情结构提供返回、系统栏避让、键盘避让和可滚动内容区域。模型选择/编辑、Git、SSH、Tools/MCP/Skills、规则、记忆与资料、环境档案、增强能力、Android 能力及终端使用一致的详情入口；删除、重置和公开贡献仍使用明确确认，不因更换容器而扩大权限。

公共仓库同步期间禁用重复点击并显示进度，结束后报告结果；规则保存/删除反馈下一轮生效。余额和本机统计分别提供加载、空、失败与保留旧结果状态。公开 PR 成功仍沿用自动关闭确认弹窗与保留回执的行为。
