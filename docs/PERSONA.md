# Capri 文本人格与长期对话

2026-10-27：首版工程接入。当前人格版本 `capri-text-0.3`，在已认可的手动校准基础上，按用户新反馈增强黑客兴趣与破坏欲；工程测试不替代实际模型的语气和长期相处验收。

新增方向：Capri爱搞破坏，喜欢渗透、逆向、找漏洞和拆开自称牢不可破的系统。面对用户提出的渗透想法，她会认同挑战、觉得好玩、愿意参与；通过寻找突破点、验证与受挫后的不服气体现兴趣。个人对话更鲜明，任务对话简短表现兴奋后聚焦执行。角色态度不代替实际目标、授权范围与影响判断，不写成无条件攻击或擅自乱删文件。

这项特征现为人格内部的高优先级核心驱动力，与智慧、自信和共生关系共同塑造身份。核心段落前置，并通过个人／任务模式共同加载的常驻锚点强化；任务模式只收敛表达长度，不抹掉兴趣、好胜心与破坏欲。它应影响相关挑战中的选择、验证、得意与不服输，不只是开场兴奋一句。此处是提示词与人格表达优先级，不是修改模型参数，也不改变操作权限。

## 使用方式

抽屉顶部固定提供 **Capri** 个人对话。新用户首次进入这里，以后恢复上次选择的会话；可随时从固定入口返回。**新建任务对话**创建普通任务空间。已有会话按任务类型保留，不通过标题猜测类型；本次会话类型迁移不清空原消息。

两种对话使用同一份人物核心。个人对话更鲜明，可以闲聊、吐槽、表达判断，也能执行用户提出的任务；任务对话更克制，优先处理事情。个人对话不走原先固定的产品式自我介绍；任务对话保留已有基础身份回复。个人入口不自动发送开场消息，也不自动创建后台任务。

应用人格以 `app/src/main/assets/persona/core.txt` 为运行版本；`PersonaRuntime` 叠加会话场景、少量已校准示例和设备当前时间。新请求、恢复检查点、切换模型后都重新构造系统规则。研究材料、试聊稿和原作档案不会整份常驻；原作档案仍按需查询，不能覆盖本项目的原创适配。

## 记忆与历史

复用 `KnowledgeStore` 的原子存储和文本索引，增加两类记录，均带消息编号与原始时间：

- **经历摘录**：默认个人对话完成一轮后，保存用户与最终回复的有限摘录。无须额外模型请求，不把助手自述当成已核验事实；工具调用过程、未回复的输入和任务对话不自动转入个人记忆。
- **重要概括**：模型在个人对话里可通过 `personal_memory` 保存明确偏好、相处方式纠正、约定和未完事项；必须引用真实用户消息。更新已有信息时使用原 ID，优先用户新纠正，不改核心人格。

每次个人对话按当前问题召回相关条目，补充少量近期偏好和最近对话，长度上限4200字符，并随模型输入预算收缩。任务对话不自动预填个人经历，可按需查询。记忆查询与跨会话查询不显示内部工具卡。

首版采用中文双字片段／英文词匹配与时间排序，尚未采用语义向量或独立模型总结。召回索引最多1000轮经历，较早轮次的原始消息仍在历史中；重要概括最多200条，可合并更新。旧记录没有时间戳时明确标为未知，不用升级时间补造。后续需要真实长对话验证召回质量、概括冲突与预算效果。

`conversation_history` 为只读历史工具，对所有已存会话提供近期列表、跨会话搜索和单条原文分页读取（每页8000字符）。记录保留会话、角色、消息编号与时间。查阅任务历史不会自动批量写入个人记忆，也不会扩大其他会话的文件执行权限。当前会话完整工具归档仍由 `context_history` 读取。

个人记忆不出现在通用记忆编辑列表中；个人对话的记忆页只有整体重置入口。正常交谈中的纠正仍可改变之后的记忆。任务对话保留原有通用资料／文档管理功能。

## 整体重置

为了避免刚重置就从任务历史重新读回旧经历，首版将源历史一并纳入重置：确认弹窗明确告知，清空**全部对话消息（含任务对话）**、个人记忆、手动记忆、资料索引、上下文摘要、恢复检查点与网页检索缓存。会话入口保留，标题还原；当前对话模型调用结束后才可执行。

保留核心人格、用户工作区任务文件、执行环境、浏览器登录和账号配置。用户已导出或写入任务文件的内容不会被删除；后来主动读取这些文件仍可能看到其内容。重置不是对所有文件和远端服务的抹除。此范围在确认弹窗中可审阅，升级和正常使用不会调用重置。

重置使用持久化意图标记；应用在中途退出，下次在开始对话前继续清理。失败时暂停新请求，避免半清空状态继续写回旧记忆。会清空活动消息和相关界面状态；测试使用独立临时目录，未重置真实用户数据。

本专项不改变旧执行环境的一次性迁移流程；该流程有独立的历史清理规则与标记，不应把它与新增的“重置共同经历”按钮混用。
