# 公共 Skill 库与用户贡献

2026-11-02。公共仓库为 [cardchoosen/capri-skills](https://github.com/cardchoosen/capri-skills)。本轮只实现公共 Skill 分发和用户明确确认后的 PR 贡献，不包含个人私有备份、聊天上传或运行产物同步。

## 自动获取与更新

首次启动及应用恢复前台会登记原生 `JobScheduler` 网络任务，后续约每六小时检查；前台自动登记检查至少间隔一小时，失败不高频重试。运行页“公共 Skills”可关闭自动同步或立即同步。下载不要求 GitHub 账号，不准备 Python/Linux，也不调用模型。Android 调度受系统约束，不承诺准时或强行停止应用后仍能运行。

同步先匿名读取固定仓库及其默认分支提交，再从该不可变 commit 下载 `index.json` 和资源。目录最多 100 个 Skill／500 个文件／10 MB；每个公开贡献最多 50 个文本文件／1 MB，资源路径使用可移植 ASCII 名称。核对文件长度、SHA-256、整包摘要及 Skill 元数据后，完整发布缓存指针。缓存缺失或损坏时重新获取；下载中断、摘要不符、非法路径或元数据错误均不替换为半套缓存。最多保留当前和一个历史缓存版本。

完整缓存再通过既有 Skill 导入锁、版本档案与导入器安装。内置 Skill、同名个人 Skill、本机修改过的公共 Skill不会被覆盖；用户删除过的公共 Skill不自动重新安装。上游撤回的未修改公共 Skill被停用，文件和本地版本仍保留；本机已修改的版本不因此被删除。启用状态沿用现有配置。安装和更新不会执行资源，也不会授予权限。

这不等于持续全量 `git pull`，不要求用户配置 Git，未做变化的普通使用无需额外交互。初始公开仓库索引为空是有效状态，不能据此声称已有一批公共 Skill 可下载。

## 创建后询问公开贡献

第一方 `skill-creator` 增加英文发布指导：先完成本地保存、元数据／资源校验和必要的小样验证，再整理一份可公开的工作区副本，调用 `skill_hub action=prepare`。

模型只能调用 `status / prepare / list / read`，没有批准、提交或合并动作。`prepare` 冻结整包资源，生成内容摘要和会话内回执，在手机显示“是否公开贡献这个 Skill？”及文件清单、逐文件分页预览。模型回复、工具参数 `confirmed=true` 或一般 `ask_user` 答案都不能代替原生确认，也不应通过 shell／Git／HTTP／MCP 绕过确认。

用户可选择“确认公开并提交 PR”“仅本机使用”或“稍后”。拒绝不影响本地安装与使用，同一内容版本的拒绝／已提交选择会被记住，不在其他聊天重复询问。稍后保留原冻结预览。收到并持久化 PR 成功回执后，确认框自动关闭并显示简短成功提示，无需再点“知道了”；已提交的 PR 链接仍保留在工具回执中，可通过 `skill_hub list/read` 查询。失败或响应未确认时保留重试入口，不能仅因用户点击确认或远端可能已有 PR 就显示成功。

原生确认明确说明：文件会使用用户自己的 GitHub 账号公开上传，分支／fork 在 PR 审核合并前就已经公开，贡献采用仓库 MIT 许可。用户应确认有权发布所有包含内容。检测会拒绝常见凭据、隐藏文件、符号链接、依赖目录及不支持的二进制资源，但不是通用隐私证明；创建器和用户仍须核对私人路径、个人信息及第三方许可。

公开上传只包含冻结副本的 Skill 文档与必要文本资源，不收集聊天、账号、登录态、环境或进程日志。预览之后的工作区修改不会悄悄进入提交；冻结文件发生变化则拒绝发布，必须准备新预览。

## GitHub 授权、PR 与恢复

沿用全局 GitHub 账号的 Keystore 加密凭据。下载始终匿名；授权头只发送到固定 `api.github.com`，不跟随重定向。APK 不内置公共写入 Token，也不把 Token 交给模型、回执或提交内容。

普通贡献者向自己的 `capri-skills` fork 创建固定内容版本的贡献分支并提交 PR；仓库拥有者也使用贡献分支和 PR，不直接更新 main。需要当前账号具有 fork／目标分支内容写入及提交 PR 所需权限。细粒度 Token 未覆盖目标 fork、授权失效、账号切换或 fork 尚未就绪时，保留回执并提示核对后重试，不自动扩大 Token 权限。

文件通过 Git blobs/tree/commit API 成组提交，贡献只改 `skills/<id>/`；旧资源明确删除，其他 Skill 不受影响。提交 SHA 在公开创建引用前落盘。固定分支名、分支内容核对及现有 PR 查询用于恢复：响应丢失时先查已有结果，不盲目重复创建 PR、不强推、不自动合并。应用重启后 `publishing` 属于未确认状态，由用户主动重试核对；不会静默重放公开操作。单次发布有 120 秒上限。

已准备的冻结文件每聊天最多 32 份、每份 1 MB；跨聊天选择索引最多 512 项。达到容量明确拒绝，不删除去重依据再当作新贡献。删除聊天或重置共同经历先取消对应发布，再清理本地预览／回执；已公开的分支、PR 和远端内容不会因此被删除。公共缓存、安装的 Skill 和简短公开选择记录不属于聊天记忆。

当前批准入口在手机原生界面。Web 对话可以准备贡献，但需要在手机确认；本轮未提供 Web 批准接口。尚未公开或合并的私人 Skill 不会因为公共同步而自动备份，卸载仍可能丢失。

## 公共仓库维护

仓库包含 README、MIT 许可、`tools/catalog.py`、索引和 GitHub Actions 工作流。镜像模板保存在 Capri 项目的 `tools/public_skills_repository/`，方便复核和维护。工具不执行提交的脚本，只检查文件范围、容量、元数据和常见敏感内容，并生成与 Android 一致的整包摘要。

PR 运行只读权限校验；维护者审核合并后，main 的工作流自动重建并提交索引。索引尚未生成或工作流失败时，客户端继续看到上一版完整目录，不把“已提交 PR”视为“所有设备已可获取”。管理员应在仓库设置启用审核与校验要求；本轮没有擅自设置可能阻止仓库拥有者合并的分支保护规则。
