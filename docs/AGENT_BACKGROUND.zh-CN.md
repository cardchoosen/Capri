# Agent 后台执行与限时网络重试

> 2026-11-03：运行所有权和宿主生命周期已由[内核独立专项](KERNEL_INDEPENDENCE.zh-CN.md)推进；以下保留首轮改造记录。当前控制器不再继承 ViewModel，服务在任务结束后保留待命、释放 CPU 唤醒锁，支持无页面 Web 启动。30 秒重试边界不变。第二批补齐深度省电豁免入口、统一系统策略状态和可选解锁后恢复待命；长期设备验收按用户要求跳过。

## 问题依据

2026-11-02 的真机对照中，代理没有启用，仅将 Capri 切到桌面，应用 UID 的域名解析就从成功变成 `unknown host`，网络策略从 `effective=NONE` 变为 `effective=APP_BACKGROUND`；返回前台后立即恢复。历史任务还出现进程冻结。报“模型域名解析失败”不能直接认定为 DNS 服务器故障。

## 运行所有权

手机页面通过 `AgentRuntime` 获取进程级的会话控制器，Web 桥继续访问同一实例。会话、工具与恢复状态由进程级 owner 保留；Activity 重建或销毁不再销毁运行状态。`CapriModel` 暂保留现有类型名和状态接口，便于兼容手机/Web；其 owner 不再是 Activity。

实际 Agent 任务由 `AgentTaskEngine` 的独立 SupervisorJob 和协程作用域管理，不使用页面协程作用域。每个会话仍最多一个执行任务，不同会话可并行。页面的“停止”只取消当前会话，前台服务通知里的停止操作取消当前全部 Agent 任务。停止不会关闭独立持续终端，也不会撤销已经执行的工具效果。

每轮任务在调用模型或执行工具之前等待前台服务启动回执。`AgentTaskService` 显示运行通知、任务数量、返回入口和停止按钮；最后一个任务结束后移除通知并停止服务。前台服务启动失败或回执超时，本轮不会开始执行，并明确提示返回 Capri 前台重试。环境准备、持续终端的服务保持独立。

服务使用适配当前用户可感知任务的 `specialUse` 类型，应用现有相关权限不变。没有任务时不常驻服务。系统杀进程或用户强行停止后，不自动重启任务、不自动重放工具；沿用已有检查点核验和显式“继续”流程。前台服务降低后台网络限制和冻结风险，不承诺抵抗强行停止、极端内存压力或所有厂商策略。

## 最多 30 秒重试

首次网络请求保留原有正常请求超时。第一次遇到可重试错误后，启动 **30 秒共享恢复窗口**，包括后续退避等待和重试请求耗时。采用 1、2、4、8 秒后上限 8 秒的退避，最后一次等待或请求受剩余窗口约束；窗口到期即结束当前模型请求、保留任务检查点，不监听网络永久等待，也不在之后自动恢复。

只重试模型传输，不重放工具；沿用同一模型配置、50 次全局请求预算、各用途预算和最终交付预留。预算不足时可早于 30 秒结束。401、TLS 校验失败、协议错误、格式错误不重试；可重试 HTTP 状态尊重 `Retry-After`，超过剩余窗口则直接保留失败。用户停止可取消等待和在途请求。

Android 15 起，生命周期外的网络访问可能抛出 `UnknownHostException`。参考：[后台联网限制](https://developer.android.com/about/versions/15/behavior-changes-all#background-network-access)、[前台服务](https://developer.android.com/develop/background-work/services/fgs)。

## 验证范围

相关 JVM 检查覆盖恢复窗口、慢重试请求截止、初次请求超时不被缩短、预算、取消、不可重试错误和不重放工具。单个隔离真机用例覆盖实际前台服务回执、多任务、Activity 重建/销毁后继续运行、通知停止和最后任务退出后关闭服务；不发送真实聊天、不调用真实模型。

2026-11-02 验证结果：独立提交源码构建通过，31 个相关 JVM 检查通过；上述单个真机用例通过（2.329 秒）。手机保留数据更新。构建、检查和提交隔离清单保留在 `work/agent-background/`，生成物不提交。没有通过真实模型任务、修改代理配置或系统冻结开关来验收。
