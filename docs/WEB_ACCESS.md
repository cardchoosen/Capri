# 开发设备网页入口 · 首版

Mac 上运行 `python3 tools/capri_web.py`，打开终端输出的访问链接。单台已授权 USB 手机自动选择，多台设备用 `--serial`；默认端口 47863，可用 `--port` 更改。手机安装 Debug APK 并保持 Capri 进程运行；Ctrl-C 关闭网页入口。Release APK 不包含此桥接。

网页 → Mac 本机 HTTP → ADB转发的持久Unix socket → 手机现有 CapriModel。ContentProvider仅用于首次获取受保护的连接信息；每个后续请求不再启动ADB/content命令。会话、消息、工具执行及凭据都由手机原有实现管理；网页没有独立模型配置或聊天数据库。支持会话列表、新建任务会话、历史分页、发消息、停止当前任务、工具折叠和最终回复渐进展示。网页切换及新建会话在手机处于对话Tab时同步选中；手机在文件/运行Tab时保留当前上下文，不主动跳转Tab。双端发送复用sendTo。首次加载历史立即显示；新最终回复采用展示动画，模型网络协议保持现状。

Mac网页只绑定 127.0.0.1，每次启动随机访问令牌，通过 URL fragment 交给浏览器标签页，再从地址栏移除。API 同时校验 Host、Origin 与令牌；不使用 CDN、不记录聊天访问日志、模型文本以 DOM 文本渲染。会话内容从 ADB 到网页内存，浏览器 sessionStorage 只存令牌、会话 ID 和未确认操作 ID，不存聊天正文。网页与原生权限相同，不额外授予 Root 或权限。

手机Unix socket按需启动，仅接受shell/root/本应用UID，并额外校验手机端随机令牌；不监听手机TCP/LAN端口。Mac复用一条已授权连接，退出移除自有ADB转发。读取每约0.25秒（运行中）/0.75秒（空闲）轮询，隐藏网页约2秒，无并发轮询。通过epoch/revision在状态未变化时只返回小型确认，跳过消息序列化和DOM重绘。消息按原始索引分页，内部工具继续隐藏，单条及每页输出有上限；长内容明确显示节选。最终回复Markdown只解析一次，之后以最多约32ms一帧更新既有文字节点；新消息仅在阅读位置接近底部时跟随。最近5个会话在网页内存暂存视图和阅读位置，点击优先恢复后再向手机核对。接口在 Android 主线程访问同一 ViewModel，避免多实例和并发写入。

每次手机进程启动有独立 epoch，网页发送、新建和停止需匹配；重连不会自动重发操作。发送复用 DebugBridge 的 UUID 去重（进程内最近 100 个请求），新建在进程内保留最多 1000 个 UUID。读请求可在连接失效后重连一次，发送/新建/停止等变更请求绝不因传输失败自动重放。结果未确认会保留操作标识并阻止继续提交，用户核对手机历史后手动解除；不承诺跨进程 exactly-once。手机进程被系统终止时需要重新打开 Capri。

已支持会话内已发送附件的图片/GIF显示及原文件下载；尚不含任意工作区浏览、浏览器视图预览、网页模型管理、电脑端通知或公网访问。停止仅取消当前 Agent 循环，之前启动的持续终端遵循原有生命周期。

性能实测（Pixel 8a/Mac，2026-10-28）：旧通道10次完整状态读取中位1313.84ms；持久通道首次约1411ms，后续9次中位20.72ms；20次未变化读取中位5.205ms，返回134字节（完整状态约49KB）。只代表桥接开销，不含模型推理与工具耗时。合成Markdown动画保持最终文字一致，移除每帧子树重建。

验证：`python3 -m unittest discover -s tools -p test_capri_web.py -v`；Android 专项 `WebBridgeDeviceTest` 与原有 `DebugBridgeDeviceTest`。前者验证共享消息、同 ID 重复提交、新建去重、手机发送同步、历史分页、旧 epoch 拒绝以及手机其他Tab不被网页打断。

## 会话删除

手机抽屉与网页列表都可以删除任务会话，先确认，再统一调用CapriModel.deleteSession；默认PERSONAL会话没有删除按钮，后端也拒绝删除。正在执行Agent任务时先停止；删除只关闭目标会话的终端、MCP连接、网页和文件传输，其他会话继续运行。

删除消息索引、工作区、HOME/依赖/日志、上下文与检索归档、恢复检查点、会话知识及会话模型选择；模型账号、全局SSH/Git、共享Ubuntu和全局记忆保留。当前会话删除后，手机和网页各自回到默认Capri会话；其他会话的选择保持不变。网页清除已删除会话缓存，重连不会恢复它。

独立session-deletions收据保留未完成清理，启动时先从会话索引排除，再重试；清理不跟随子目录符号链接，非法ID或父目录符号链接会中止。每会话环境锁、RuntimeGate和文件导入租约防止准备任务或导入在删除后重建目录。WebView已加载的Profile可能不能立即移除，其收据保留到下一次应用进程启动继续清理，见[Android ProfileStore](https://developer.android.com/reference/androidx/webkit/ProfileStore#deleteProfile(java.lang.String))。

验证：3项SessionDeletionTest覆盖范围隔离、重复清理、子链接不越界与父链接/非法ID拒绝；SessionDeletionDeviceTest覆盖默认/运行中保护、当前会话回退、真实终端记录清理、私有归档/检索缓存删除、邻近会话及模型配置保留。实际Chrome验证确认/取消、双页同步、刷新不复活和默认接口拒绝。功能测试通过网页发送身份问题，不消耗模型请求。


## 双端界面同步与附件（2026-10-28）

会话列表、选中项和删除进度采用Compose可观察状态；抽屉标题按更新版本取快照，避免可变对象被跳过重绘。MainActivity使用singleTask，避免重复主界面持有不同ViewModel。web_select在手机对话Tab调用统一select；其他Tab不改变手机当前会话，网页各自仍可浏览其他会话。

图片是统一attachment消息，Agent和send_file不需要按网页连接状态改变行为。网页解析原有元数据，懒加载已发送图片，保留尺寸占位、说明和下载按钮。POST /api/attachment同样校验本机Host、Origin和令牌；手机按epoch、chat_id和消息索引检查确为当前会话已发送附件，并校验原文件大小/修改时间，不接受任意路径。Main只解析元数据，文件分块读取在socket工作线程，每块最多64KB，经USB逐块返回再由Mac流式发送；图片/GIF字节不重编码。浏览器用内存Blob显示，切换或删除取消读取并撤销URL；其他文件只提供下载，不执行HTML/SVG。

本轮验证：124项JVM、10项宿主、4项真机通过。WebSyncDeviceTest直接操作实际手机抽屉并检查条目消失，覆盖对话/运行Tab条件、附件字节与跨会话/旧epoch/越界路径拒绝。Chrome用用户原有quicksort_visual.png验证1822×1296解码、98925字节原图下载、原始JSON隐藏和手机选中同步，无页面脚本错误；未重画或调用模型。
