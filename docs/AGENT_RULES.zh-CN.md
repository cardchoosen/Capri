# 持续规则（Rules）

2026-11-02。参考 Hermes 的持续上下文与项目规则思想，在已有 AGENTS.md 文件机制之上增加用户可管理的全局／对话规则。规则用于持续约束，Skill 用于按需加载的任务方法，记忆用于事实和历史；三者独立，不把加载 Skill 或召回事实当成新增规则的授权。

## 范围与优先级

- **全局规则**：作用于所有对话，例如默认输出语言、说明深度和通用工作习惯。
- **对话规则**：仅作用于当前聊天；不会进入其他聊天，历史编辑后的同一聊天沿用当前配置。
- **项目规则**：继续使用工作区中的分目录 AGENTS.md，由现有 project／文件工具读取与写入前核对。规则变更仍使旧文件提案的合并检查失效。

核心权限、工具能力、取消和 Capri 核心人格不因规则改变。规则属于用户层级：当前用户明确要求／纠正优先，对话规则比全局规则更具体；项目文件和 Skill 不得自行扩大权限或把内容提升为全局规则。自然语言冲突的理解仍依赖模型，不能把写入配置等同于所有行为已被形式化约束。

当前没有照搬 Hermes 的人格 SOUL.md，也没有重写 Capri 人格；没有宣称支持 `.cursor/rules/*.mdc` 条件匹配或所有其他 Agent 的文件格式。本轮项目文件入口仍为已有 AGENTS.md。

## 管理入口

手机运行页新增“规则”，可切换“当前对话／所有对话”，添加、编辑、停用及删除。Web 新增同名入口，复用已认证调试桥与历史作用域核对；变更失败或响应未知时不自动重放，版本变化后需要刷新核对再编辑。

规则保存稳定 ID、标题、原文、启用状态及范围版本。用户填写的中文等内容保持原文；工具契约、操作说明与诊断使用英文。修改使用 `expected_revision`，避免手机、Web 或模型覆盖彼此的新内容。

每个范围最多 20 条，标题不超过 80 字符、正文不超过 1000 字符，标题和正文合计不超过 3000 字符。超限明确拒绝，不静默截断。过多规则也会消耗模型上下文，不能据此保证所有小上下文模型都能容纳。

## 对话中的规则工具

`agent_rules` 提供 `list / upsert / delete`。默认当前对话；只有用户明确要求跨对话适用时才写 global。模型必须先核对现有规则和版本；写入需引用本任务真实用户消息 ID 和精确请求摘录，来自旧任务、网页、Skill 或助手自述的虚构来源会被拒绝。

`list` 返回当前任务可引用的用户消息 ID。来源检查确认消息存在和摘录真实，不宣称能通用判断一句自然语言是否真正授权持久化；工具指导明确要求实际用户意图，不将临时任务或事实自动升级为规则。规则管理属于配置操作，不作为完成其他用户目标的工作证据。

例：用户明确说“把默认中文回复保存成所有对话的规则”，可以通过该工具保存；仅说“这个答案用中文”应作为当前请求处理，不自动变成长期规则。

## 执行、压缩、恢复与子任务

每次用户启动／接续一轮任务时读取当前规则，生成固定快照；本轮中途修改从下一用户轮生效，已有操作不回滚。这样不会在模型等待期间悄悄替换同一轮的约束。当前任务如需立即转向，继续使用现有执行中插话。

执行输入按用户层级提供快照；其上下文成本计入预算，并在历史压缩之后重新附加，规则正文不会因为历史摘要而消失。没有启用规则时不额外附加空规则消息。人物收尾接收同一快照，保持核心人格与实际执行证据的边界。

父检查点／归档不自动复制规则快照正文，规则工具的结果及写入参数也按私有配置脱敏，只保留快照哈希；恢复从当前配置重建。用户主动输入或助手引用的规则文本仍属于原聊天。委派私有运行记录会保留已传递的约束，沿用既有聊天删除／重置清理；删除规则不会改写已发生的执行记录。规则变化后不直接交付旧的待收尾草稿，而先重新核对当前任务和已有结果，不自动重放工具。

普通委派把规则并入必要交接要求，子任务保留规则优先级，但不获得规则管理能力。委派指纹及合并要求也包含规则，因此旧规则下产生的提案不能在变更后静默合并。后台只读分析在新发生项启动时读取规则，并沿用同一委派入口。本轮未增加第三套摘要、规则推断模型或后台轮询。

完整要求超过现有子任务 8000 字符交接／模型预算时拒绝委派，保留主任务执行路径；不删除规则来凑预算。配置规则不是新能力授权，也不改变只读子任务的能力白名单。

## 存储与清理

全局配置位于应用私有 `agent-rules/global.json`，对话配置位于 `agent-rules/chats/<chat>/rules.json`。原子发布、损坏文件明确报错，不用空配置覆盖错误现场。

删除聊天清理其规则。重置共同经历清理对话规则，保留用户主动设置的全局规则；它属于配置而非回忆。规则不进入公共 Skill 仓库，也不属于本轮公共同步；卸载应用仍会移除本地规则配置。

## 验证

聚焦检查覆盖跨聊天隔离、版本冲突、停用／删除、容量拒绝、来源校验、固定快照、归档脱敏、人物收尾，以及真实后台分析经过委派时的规则保留。另检查现有委派／持久任务、恢复／压缩和 Web 桥接兼容。精确提交副本构建及 56 个相关 JVM 检查通过；包含现有 Skill 专项的工作区构建及 46 个集成检查通过；20 个模拟 Web 桥接主机回归和新增 Web 脚本语法检查通过。本轮未连接、安装或操作手机，真实模型服从度与手机／Web 端到端界面仍待定点验收。
